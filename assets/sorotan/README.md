# Aset Sorotan

Folder ini khusus untuk gambar sampul dan aset visual Kanal Sorotan Kegiatan di beranda.

Simpan gambar sorotan di sini dengan nama berkas yang jelas, misalnya:

- `festival-seni.webp`
- `pameran-rupa.webp`
- `hari-anak.webp`
- `semesta-buku.webp`
- `kegiatan-guyub.webp`
- `arsip-tahunan.webp`

Setelah gambar ditambahkan, perbarui atribut `src` pada kartu sorotan di `index.html` agar menggunakan path lokal, seperti `assets/sorotan/festival-seni.webp`.
